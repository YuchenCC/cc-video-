# Acceptance Checklist

## 工程结构
- [ ] 是否创建完整目录结构？
- [ ] 是否包含 docs、assets、src、scripts、exports？
- [ ] 是否包含组件目录？
- [ ] 是否包含样式 token 文件？

## 工程记忆
- [ ] PROJECT_MEMORY.md 是否明确项目风格？
- [ ] 是否写明核心原则？
- [ ] 是否写明禁止项？

## 视觉规范
- [ ] 是否使用浅灰白背景？
- [ ] 是否使用扁平化 SVG 图标？
- [ ] 是否使用蓝绿、深蓝、珊瑚粉等主色？
- [ ] 是否避免复杂 3D 和强光效？

## 镜头节奏
- [ ] 是否每个分镜只解释一个概念？
- [ ] 是否单分镜控制在 8–20 秒？
- [ ] 是否每 2–4 秒有一次视觉变化？

## 动画规范
- [ ] 是否使用 fadeIn、slideUp、popIn、arrowDraw、typewriter 等轻量动画？
- [ ] 动画是否服务于理解？
- [ ] 是否避免无意义漂浮和过度弹跳？

## 转场规范
- [ ] 是否以 fadeToNext、slideReplace、localReplace 为主？
- [ ] 是否避免强闪白、复杂 3D、粒子爆炸？

## 字幕规范
- [ ] 字幕是否位于底部居中？
- [ ] 是否使用黑色半透明圆角背景？
- [ ] 是否控制在 12–22 个中文字？
- [ ] 是否作为口播摘要，而不是逐字稿？

## 整体体验
- [ ] 是否像程序员小课堂？
- [ ] 是否清晰、轻量、低压？
- [ ] 是否没有 PPT 堆字感？
- [ ] 是否没有炫技抢内容？
