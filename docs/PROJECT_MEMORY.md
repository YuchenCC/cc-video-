# Project Memory

本项目是一个 Hyperframes 技术科普视频工程，目标是复刻一种程序员技术讲解类白板动态图解风格。

## 核心原则

- 复杂技术概念必须图解化。
- 每个分镜只解释一个概念。
- 画面使用浅灰白背景、扁平化 SVG 图标、流程箭头、终端窗口和圆角卡片。
- 镜头不追求快切，而是通过元素逐步出现推动理解。
- 每 2–4 秒必须有一次视觉变化。
- 转场保持克制，以淡入淡出、局部替换和滑入为主。
- 动画服务于理解，不做炫技。
- 字幕是口播摘要，不是逐字稿。
- 整体氛围应轻松、清晰、程序员友好。

## 默认画面规格

- 画幅：16:9。
- 分辨率：1920×1080，兼容 1280×720。
- 帧率：30fps。
- 单分镜：8–20 秒。
- 单画面：一个概念、一个中心图解、3–5 个核心元素、一条主流程线。

## 禁止项

- 不做赛博朋克风。
- 不做强光效科技风。
- 不做复杂 3D。
- 不做大段文字堆叠。
- 不做花哨综艺转场。
- 不用无意义漂浮、频繁弹跳或快切制造节奏。
