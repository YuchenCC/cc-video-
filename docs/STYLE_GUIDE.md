# Style Guide

## 视觉关键词

技术科普、白板动画、扁平化图解、程序员小课堂、浅色背景、流程箭头、分层结构、终端窗口。

## 色彩

| Token | 色值 | 用途 |
|---|---|---|
| background-primary | `#F7F8FA` | 主背景 |
| background-secondary | `#F4F6F8` | 次级区域 |
| primary-blue | `#2F6F8F` | 主强调 |
| deep-blue | `#233B5E` | 标题、深色结构 |
| teal | `#2C9A9A` | 流程、技术对象 |
| green | `#3CAEA3` | 成功、可用状态 |
| coral | `#EF7B85` | 问题、对比强调 |
| light-gray | `#D9E1E8` | 边框、分隔 |
| medium-gray | `#AAB4BE` | 次要信息 |
| dark-gray | `#333333` | 正文 |
| terminal-bg | `#1F2933` | 终端背景 |
| terminal-text | `#E5E7EB` | 终端文字 |
| subtitle-bg | `rgba(40, 40, 40, 0.75)` | 字幕背景 |
| subtitle-text | `#FFFFFF` | 字幕文字 |
| highlight-yellow | `#FFE08A` | 局部高亮 |

## 字体

- 标题：圆润无衬线，字重 600；中文优先思源黑体、苹方或 Noto Sans CJK。
- 标签：圆润无衬线，字重 500。
- 正文：圆润无衬线，字重 400。
- 字幕：白色、字重 400，字号小于画面标签。
- 代码：JetBrains Mono、Menlo 或 Fira Code。
- 英文：Inter、SF Pro 或 Noto Sans。

## 图形

- 使用扁平化 SVG，保持统一描边粗细和圆润端点。
- 卡片圆角为 8–16px，仅使用轻阴影。
- 图标可以适度拟物，但不能写实。
- 箭头的线宽、箭头头部和标签样式保持一致。

## 构图

- 核心图解居中，左右对比和上下分层作为辅助。
- 流程默认从左到右；箭头承担信息引导。
- 底部预留固定字幕安全区，右上预留低存在感水印。
- 保持充足留白，文字只解释图形无法表达的部分。

## 禁止项

禁止赛博朋克、强炫光、厚重渐变、复杂 3D、真实截图堆叠、PPT 式大段文字和花哨综艺视觉。
