# Transition Rules

## 推荐

- `fadeToNext`：新概念整体淡入淡出。
- `slideReplace`：同区域模块滑入替换。
- `wipeSoft`：柔和擦除。
- `zoomSlight`：轻微缩放进入。
- `objectMorph`：同类对象形态变化。
- `localReplace`：同一概念内局部替换。

## 使用原则

- 新概念切换使用淡入淡出。
- 同一概念推进使用局部替换。
- 流程推进使用箭头绘制或模块滑入。
- 对比变化使用左右滑入或透明度切换。
- 结构演化使用对象 morph 或层级展开。

## 禁止

- 强闪白
- 快速旋转
- 复杂 3D 翻转
- 粒子爆炸
- 大幅甩镜
- 过强光效
- 过度弹跳
