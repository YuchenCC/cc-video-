# Scene 001 — 综述

- 时长：28 秒
- 核心概念：接入一个 Java 脱敏组件后，统一覆盖接口响应、日志输出和主动脱敏。
- 章节标题：无，0 秒直接进入正文。
- 构图：使用 `concept-expansion` 主场景语法。中央先出现电脑、文件、Java 组件嵌套图标；随后出现由 `StackFrame` 和三个 `StackLabel` 组成的入口清单；“接入组件后”阶段不再让清单退场，`plug.png` 从右上以 2 倍尺寸飞入解释接入动作，随后消失并替换为带白底的 `java_logo.png`，固定在 StackFrame 右上角作为已接入状态。
- 区域：画面按 25% / 50% / 25% 分为左、中、右三块；中区顶部和底部各留约 22% 安全空间。图片概念保持比例、顶部对齐并限制为约 440px 高，确保与字幕之间存在明确间隔；StackFrame 在接入阶段继续停留于中央主视区，人物固定在右区。
- 人物：`assets/characters/9.png` 表达人工排查疲惫；完成覆盖后局部替换为 `assets/characters/17.png`。
- Beat：组件定义 → 三类入口 → 人工排查疲惫 → 接入脱敏组件 → 三项依次覆盖并打钩 → 成功状态保持。
- 主动画：电脑、文件和 Java 作为一个复合图标同时入场并同时退场；随后 StackFrame 逐项生成、plug 从右上放大飞入并增强现有 StackFrame、plug 淡出后白底 Java 标识接管、StackLabel 逐项替换、CheckBadge 依次绘制、人物局部替换。
