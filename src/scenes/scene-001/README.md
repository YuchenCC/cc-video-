# Scene 001

## 画面目标

作为视频开场封面，展示主题大图并安静进入下一幕。

## 口播内容

无口播。

## 字幕摘要

无字幕。

## 画面布局

`assets/ppt/01-cover-pptmob-v3-cib-fintech-ai.png` 覆盖 1920x1080 全屏画面。
图片使用 `object-fit: cover`，背景兜底为浅灰白 `#F7F8FA`。

## 动画步骤

1. 0.1s：封面图 `fadeIn`。
2. 0.4s-3.5s：封面图保持全屏展示。
3. 3.5s-4.0s：浅灰白覆盖层淡入，作为下一幕的 `fadeToNext` 转场准备。

## 转场

`fadeToNext`。

## 验收标准

- 只展示指定封面大图。
- 不出现口播、字幕、水印、人物或额外说明文字。
- 画面覆盖全屏，无黑边。
- 总时长约 4 秒，末尾有淡入转场。
